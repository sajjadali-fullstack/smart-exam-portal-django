## ***Idea came while commuting in Mumbai local train — wanted a platform to revise programming concepts on the go. Built Smart Exam Portal with Django featuring category-based quizzes, difficulty filters, leaderboard, and answer review system.***

# 🎯 django-smart-exam-portal

A dynamic, secure, and fully responsive online examination platform built using the **Django Framework** and **Bootstrap 5**. This portal allows users to take category-wise tests based on difficulty levels, features a secure backend integrated with **MySQL**, and uses an automated countdown timer with auto-submit capabilities to ensure a fair testing environment.

---

## ✨ Features


- 🔐 Secure User Authentication (Login, Register & Logout)
- 📚 Category-Based Quiz System
- 🎯 Easy, Medium & Hard Difficulty Levels
- ⏳ 5-Minute Countdown Timer with Auto Submit
- ✅ Instant Score Calculation
- 📖 Detailed Answer Review & Explanations
- 🏆 Global Leaderboard (Hall of Fame)
- 📈 Platform Statistics Dashboard
- ⭐ Feedback & Reviews System
- 📱 Fully Responsive UI (Bootstrap 5)
- 🚨 Custom 404 & 500 Error Pages
- 🗄️ MySQL Database Integration
- 🔒 Environment Variables using `.env`
